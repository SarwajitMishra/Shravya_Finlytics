# **App Name**: Shravya Finlytics: AI Financial Insights

## Core Features:

- Real-time Market Sentiment Analysis: Analyze real-time market sentiment by processing financial news from sources like NewsAPI and public NSE feeds. This tool will assign sentiment scores to various stocks and industry sectors.
- Financial News Summarization: Summarize financial news from RSS feeds or user input using LLMs. This tool will categorize news into economy, earnings, policy, and global impact themes.
- Investment Assistant: Provide an AI chat interface that instantly responds to financial questions. The assistant should auto-analyze user prompts (e.g., ‘Should I invest in Infosys?’ or ‘Review Reliance Q4 performance’) and deliver data-backed summaries, trends, and advice in real-time.
- Visual Dashboards: Display stock charts (candlestick, line, bar) using libraries like Chart.js or Recharts. Include live financial indicators such as PE ratio, EPS, and volume. Allow users to filter dashboards by sector and company.
- Economic Events Tracker: Track key economic events like RBI meetings, earnings calls, and major IPOs. Provide alerts and AI-powered summaries of these events to users.
- User Personalization: Allow users to save watchlists and track sentiment over time. Reward daily engagement through S-Coins, and offer customizable notification settings for alerts and reports.
- Auto-Trigger Feedback: If the user mentions a specific stock or sector in chat or search, initiate an immediate review using the latest sentiment + financial indicators.

## Style Guidelines:

- Primary color: Muted blue (#5DADE2) to convey trust and stability in finance. This evokes a sense of calm and reliability, which are important in financial contexts.
- Background color: Very light blue (#EBF5FB), nearly white, which provides a clean, unobtrusive backdrop, ensuring the focus remains on the data and content.
- Accent color: Soft green (#A9DFBF), positioned 30 degrees 'left' on the color wheel, signifying growth and positive trends. It is less saturated than the primary blue, to ensure a gentle contrast that does not overwhelm.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text. 'Poppins' adds a contemporary, fashionable feel in moderation; while 'PT Sans' ensures readability for longer texts.
- Use clean, minimalist icons to represent financial metrics and actions. Icons should be consistent in style and align with the overall aesthetic of the platform.
- Implement a responsive, grid-based layout that adapts to different screen sizes. Ensure key information is easily accessible and prioritized based on user needs.
- Incorporate subtle animations and transitions to enhance user experience. For example, data loading animations and smooth transitions between different sections of the app.
